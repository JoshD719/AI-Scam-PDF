# README for Seller

## What the Buyer Receives
The buyer should receive **only the final exported PDF file**:

`2026-Family-AI-Scam-Defense-Kit.pdf`

Buyers do **not** need npm, Playwright, GitHub, Codex, source code, project files, scripts, or browser export instructions.

## Recommended Seller Export Workflow
Use the print-ready HTML file as the seller source file:

`family-ai-scam-defense-kit/dist/2026-Family-AI-Scam-Defense-Kit-PRINT.html`

Open it in Chrome and export it using **Print > Save as PDF**.

Recommended Chrome settings:
- Destination: Save as PDF
- Paper size: Letter
- Scale: 100%
- Background graphics: ON
- Margins: Default first, then try None if the layout looks better

Save the exported file as:

`2026-Family-AI-Scam-Defense-Kit.pdf`

Then place the exported PDF into this `/buyer-ready` folder before uploading it to Payhip, Gumroad, Etsy, Shopify, Stan Store, or another selling platform.

## Do Not Sell the Fallback PDF
Do **not** sell the plain fallback PDF generated by the Node script when Playwright is unavailable. It exists only as a technical backup to confirm a PDF can be created.

## Do Not Upload Project Files Unless Intended
Do not upload the full project folder, source HTML, JavaScript, CSS, GitHub repository, or development files as the customer product unless you intentionally create and sell a separate developer/license version.

## Final Seller Checklist
Before uploading the buyer PDF, open it and confirm:
- Cover page looks professional.
- Background graphics are visible.
- Page size is Letter.
- Pages are readable.
- Worksheets and bonus printables are included.
- Disclaimer is included.
- Source/resource page is included.
- Links work where supported by the selling platform/PDF viewer.
- File size looks realistic for a designed PDF.
